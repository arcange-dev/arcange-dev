## About

I'm Mukamyi Izere Arcange, a developer and technology builder studying **Computer Systems and Architecture** under Rwanda TVET.

I'm curious about almost every part of IT, and I like understanding how a system works at every layer. That curiosity runs from web and full-stack development, through operating systems and low-level C and C++, down to electronics, Arduino and embedded hardware. I'm also working in AI and machine learning, with a particular interest in AI agents and autonomous coding systems.

My long-term goal is to understand technology from the hardware level up to the software level, and to build useful systems, tools and applications on my own. I'm still learning, and I'm open to collaborating on web development and hardware projects.

### Hardware and electronics work

**Arduino MQ-2 Gas Monitoring System** — a practical electronics project using an Arduino Uno, MQ-2 gas sensor and buzzer. The prototype reads the sensor and activates an audible alert when the configured threshold is reached.

This project reflects my interest in connecting software with physical components and learning through hands-on experimentation.
